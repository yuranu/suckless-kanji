# suckless-kanji

Kanji stroke-drawing trainer. Client-side only, no dependencies.

## Data

```bash
scripts/fetch.sh          # downloads raw sources into raw/ (once)
node scripts/build.mjs    # joins them into web/data/kanji.js
```

| Source | Used for | License |
|---|---|---|
| [KanjiVG](https://kanjivg.tagaini.net) (release pinned in `fetch.sh`) | stroke paths + order | CC BY-SA 3.0 |
| [davidluzgouveia/kanji-data](https://github.com/davidluzgouveia/kanji-data) | readings, meanings, frequency (KANJIDIC2) + JLPT N5–N1 (tanos.co.uk) | MIT / CC BY-SA 4.0 |

`web/data/kanji.js` holds all 2211 JLPT kanji, ordered by level (N5→N1), then by frequency. Each entry has `c, jlpt, freq, grade, strokes, meanings, on, kun, paths, types`.
`paths[i]` is the SVG path `d` of stroke i, a centerline in a 109×109 box.

`ref/*.pdf` contains the tanos lists. They're kept only as a cross-check; kanji-data has the same level assignments.

## Curriculum

`data/curriculum.yaml` is generated by a script; never edit it by hand. Change `scripts/build-curriculum.mjs` and rebuild:

```bash
npm install     # once: kuromoji, used at build time only
npm run all     # fetch.sh (checksum-verified) + build.mjs + build-curriculum.mjs
```

The build is deterministic: the same inputs give a byte-identical output.
- The GitHub sources are pinned to fixed commits/releases.
- Every download is checked against `scripts/sources.sha256`.
- Tatoeba only publishes a "latest" export. If it has changed, `fetch.sh` fails; run `scripts/fetch.sh --relock` to accept the new data deliberately.

The output is a flat list of lessons, one per word+reading, in study order:
- **Levels:** it goes N5→N1. A word appears only once its JLPT level is reached and all its kanji are learned.
- **Level start:** each level begins with that level's words that use only kanji from earlier levels.
- **Kanji order:** kanji are introduced one at a time. The next one is the most frequent kanji that unlocks a word at that point; its first word carries `new_kanji`.
- **Kanji-only lessons:** a kanji that no word at its level uses gets its own lesson.
- **Examples:** these are Tatoeba sentences matched by word *and* reading, at most 32 characters. Kanji not yet learned are written in hiragana and the example is flagged `kanaized`.

The file header documents every field and lists each skipped word with the reason.

## Run

Open `web/index.html` directly, or serve it:

```bash
python3 -m http.server 8765 --directory web
```

Modes:
- **Trace**: the outline is shown and the next stroke's start is marked.
- **Guided**: blank board; the stroke animates after 1 miss.
- **Recall**: blank board; the hint appears after 3 misses.

Keys: `→`/`Enter` next, `←` prev, `r` restart, `a` animate, `h` hint.

Progress is per-kanji run/clean counts in localStorage. It's throwaway PoC state.

## Stroke matcher

`web/stroke.js` resamples the drawn stroke and the reference to 24 points. It then checks:
- average point distance,
- start/end distance (catches reversed strokes),
- length,
- shape (Fréchet distance after normalization).

Tolerances scale with stroke length. A stroke is also rejected if it fits another stroke clearly better, which catches wrong order and redrawing an existing stroke.

```bash
node scripts/test-matcher.mjs [mess=1] [sample-every=8]
```

This is a Monte-Carlo check with a simulated sloppy hand. At mess=1.5: about 99% of correct strokes are accepted, 0% of other strokes, and 98% of reversed strokes are flagged.
